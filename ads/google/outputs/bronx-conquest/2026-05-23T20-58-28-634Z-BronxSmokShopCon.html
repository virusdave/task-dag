  1. Download 01-BronxSmokShopCon-skeleton.csv and 02-BronxSmokShopCon-ads.csv.
  2. In Google Ads Editor: Account → Import → From file… and pick file 01 first.
  3. Review & post: this creates 3 Paused campaigns (BronxSmokShopCon-01, BronxSmokShopCon-02, BronxSmokShopCon-03), one ad group per campaign, and the 10458 location target on each.
  4. Import file 02 next: this creates 8 Paused RSAs spread across the 3 ad groups (max 3 per campaign).

The split into 3 campaigns honors the operator rule of ≤3 RSAs per campaign. The per-entity CSV split (skeleton vs ads) avoids the "your ad group contains no ads" failure from earlier bundles, which was caused by mixing entity types in one CSV with bespoke per-entity status columns Ads Editor didn't recognize.
