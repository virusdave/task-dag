# AGENTS

Before doing any work under this directory, read and follow `AGENTS_MUST_KNOW.md`.

This directory also contains `HOW_SWEED_WORKS.md`, which is the longer-lived Sweed knowledge base for this workspace. Consult it for accumulated learnings, confirmed API behavior, workflow notes, and prior reverse-engineering results.

This directory also contains `HOW_LITALERTS_WORKS.md`, which is the longer-lived Lit Alerts knowledge base for this workspace. Consult it for accumulated learnings, confirmed backend API behavior, workflow notes, and prior reverse-engineering results for the Lit Alerts UI and data-provider flows.

When the user says "handoff", update `AGENT_TODO.md` in the current working directory with the current state, the immediate next steps, and the larger goal so the work is ready for agent handoff. If `AGENT_TODO.md` does not exist in the current working directory yet, create it there instead of using a parent-directory handoff file.

If you learn something durable about Sweed, update `HOW_SWEED_WORKS.md` and, if it is especially important, `AGENTS_MUST_KNOW.md` as well.

Do not ignore `AGENTS_MUST_KNOW.md`. It is required reading for agents working here.
